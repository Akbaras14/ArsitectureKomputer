Pendahuluan
▼

Komputer modern terdiri dari komponen hardware dan software yang saling bekerja sama. Klik kartu di bawah untuk memahami dua konsep utamanya:

🏗️

Arsitektur Komputer

klik untuk penjelasan

Arsitektur = atribut yang terlihat oleh programmer: set instruksi, jumlah bit, mekanisme I/O, teknik pengalamatan memori.

⚙️

Organisasi Komputer

klik untuk penjelasan

Organisasi = unit operasional & interkoneksinya: sinyal kontrol, teknologi memori, clock speed, implementasi hardware.

⚡ Simulasi: Konversi Bilangan

Komputer bekerja dengan bilangan biner. Masukkan angka desimal untuk melihat representasinya:

Biner: 00101010
Heksadesimal: 0x2A
Oktal: 052

▼
AspekArsitekturOrganisasi
DefinisiAtribut yang terlihat oleh programmerUnit operasional & interkoneksinya
ContohSet instruksi, format dataSinyal kontrol, clock speed
FokusApa yang dilakukan (what)Bagaimana melakukannya (how)

Contoh: arsitektur x86 tetap sama sejak 1978, namun organisasinya berubah drastis — dari pipeline sederhana ke superscalar multi-core.

Sistem Input/Output
▼

Sistem I/O menghubungkan CPU dan memori dengan perangkat luar.

🔄

Programmed I/O

klik

CPU aktif memeriksa status perangkat (polling). Sederhana tapi boros waktu CPU.

🔔

Interrupt I/O

klik

Perangkat mengirim sinyal interrupt. CPU bisa kerja lain sambil menunggu. Lebih efisien.

⚡

DMA

klik

Direct Memory Access — transfer data langsung perangkat ↔ memori tanpa CPU. Untuk data besar.

Hazard dalam Pipeline

📊

Data Hazard

klik

Instruksi bergantung pada hasil instruksi sebelumnya yang belum selesai.

🔀

Control Hazard

klik

Percabangan (branch) menyebabkan ketidakpastian instruksi selanjutnya.

🔧

Structural Hazard

klik

Dua instruksi butuh resource hardware yang sama bersamaan.

Teknik Modern

  • Superscalar — Lebih dari 1 instruksi per clock
  • Out-of-Order Execution — Eksekusi tidak sesuai urutan
  • Branch Prediction — Prediksi arah percabangan
  • Multi-core — Banyak CPU dalam satu chip

Studi Kasus: Komponen PC
▼

Klik setiap kartu untuk melihat hubungannya dengan teori:

🧠

CPU

klik

Otak komputer. Multi-core, cache berlapis, pipeline panjang. Contoh: Intel Core i7, AMD Ryzen.

🟩

Motherboard

klik

Papan sirkuit utama. Menyediakan jalur bus (PCIe, SATA, USB) dan chipset pengatur komunikasi.

💾

RAM

klik

Memori utama volatile (DDR4/DDR5). Menyimpan data & instruksi yang sedang diproses.

🎮

GPU

klik

Ribuan core kecil yang bekerja paralel. Cocok untuk rendering grafis & komputasi matriks.

💿

SSD NVMe

klik

Penyimpanan non-volatile via bus PCIe. Jauh lebih cepat dari HDD (tanpa mekanis).

🔌

PSU

klik

Konversi AC → DC (3.3V, 5V, 12V). Sertifikasi 80 Plus untuk efisiensi tinggi.
